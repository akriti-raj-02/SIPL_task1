# To-Do List

A simple To-Do List web application built using HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Save tasks using Local Storage
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## Project Purpose

This project was created as part of my Web Development internship to practice HTML, CSS, JavaScript, and basic browser Local Storage.
